# Salut, je suis Christ 👋

Développeur **full-stack TypeScript** basé au Bénin. Je conçois et maintiens en production
un écosystème d'applications métiers pour une entreprise de services : planification,
production industrielle, CRM WhatsApp, suivi terrain, trésorerie.

## Ce que je construis

Des applications **Next.js + Supabase** qui vivent en production, avec des contraintes
réelles : plusieurs rôles et sites, une instance PostgreSQL partagée entre applications,
des équipes terrain sur mobile, du papier officiel à chaque étape.

| Domaine | Exemple |
|---|---|
| Planification & trésorerie | Planning multi-rôles, facturation, rappels automatiques (PWA + push) |
| Production industrielle | Matière première, fabrication, stock, distribution boutiques, 9 PDF officiels |
| CRM WhatsApp | Multi-agents, multi-numéros, Meta Cloud API, attribution auto, SLA |
| Suivi terrain | Supervision de vidéastes en temps réel |

## Stack

**Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Supabase (PostgreSQL, RLS, Realtime) ·
Zustand · zod · PWA / web-push**

Ce à quoi je tiens dans mon code :

- 🔐 La sécurité d'abord : RLS durcie, `timingSafeEqual`, signatures HMAC, rate limiting,
  secrets dans le Vault — et des commentaires qui expliquent *pourquoi*
- ✅ Des tests qui verrouillent la logique (fuseaux horaires compris) et un `npm run check`
  qui fait office de porte avant chaque déploiement
- 📝 Une documentation écrite pour être lue : rapports projet accessibles aux non-techniques,
  décisions techniques argumentées dans les README
